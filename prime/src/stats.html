Connect a gateway

Miners connect through a DATUM gateway, not to the pool directly. Point your gateway at this pool, then point your miner's stratum at your gateway.

This pool accepts two gateways: ratum-gateway (recommended; prebuilt binaries) and the CONVOY DATUM gateway, both on the version 3 protocol with anti-block-withholding. Other DATUM gateway builds construct their coinbase without the pool's payout split, so a block they find pays the miners nothing; this pool refuses them. Both gateways read the same config file, so switching is a binary swap.

With pool_pass_full_users, set each miner's stratum username to an address,
    optionally followed by .workername: a bare worker name is what the pool

    pool_pass_full_users wins when both are set, so an untouched config forwards
